    桌面通知
    窗口不在前台时，回复完成 / 需要授权 / 需要回答会弹出系统通知（需授权，可随时关闭）。
    背景
    动态背景由本机绘制；「性能优先」档下动态背景静止以省资源。视频仅保存在本机 IndexedDB。

    新手向导
    重新打开首次使用向导：连接模型服务商、创建默认助手与工作区。
    服务商与模型
    连接 API 服务商（API Key / OAuth）；连接后其模型会出现在顶栏的模型选择中。
    图片自动压缩
    上传图片时长边自动压缩到 1024px，降低高分辨率图片对模型 token 的消耗；GIF / SVG 不处理，关闭后按原图发送。
    聊天图片裁剪
    上传聊天图片时先弹出裁剪框（可缩放、平移、选比例）；关闭后直接发送，仍受「图片自动压缩」影响。头像始终可裁剪。
    费用单位
    显示层换算：符号（如 ¥）+ 汇率（每 1 USD 折合多少单位，如 7.2）。留空汇率 = 1（即美元原值）。
    工具超时60s
    bash 命令超过该时间会自动终止，并把超时信息返回给模型；0 = 使用 opencode 默认（120s）。模型显式指定更长时最多放宽到 600s。
    翻译模型
    建议选便宜、快的模型；留空则用当前助手的模型。翻译通过临时会话在本机完成，不写入当前对话。
    翻译提示词
    翻译思考强度
    默认「非思考」以省成本；可选值取决于翻译模型是否支持。
    OCR 模型
    优先选名称含「OCR」的专用模型；也可选任意视觉模型。识别通过临时会话在本机完成，不写入当前对话。个别专用模型在 opencode 下可能因 max_tokens / 上下文限制报错，此时改用视觉模型即可。
    OCR 提示词
    OCR 思考强度
    默认「非思考」以省成本；可选值取决于 OCR 模型是否支持。
    数据备份
    助手 / 收藏 / 草稿 / 回复版本等仅存本地。已开启自动保存：改动会定期写入 ~/.config/opencode-chat/profile.json；浏览器数据丢失时启动会自动恢复。
    按助手清理记录
    删除某个助手的全部会话记录（含本地草稿 / 收藏 / 最近记录），不影响其他助手。
